## 一、各模块实现情况

### DeepPredict（主Agent维护）
- **版本**：v1.11（v1.1调试后确认版）
- **功能**：时序预测，支持 RandomForest / GradientBoosting / LSTM / CNN1D 四种模型
- **测试结果**（每日最低温度数据集）：
  - RandomForest: R²=0.610, RMSE=2.55 ✅
  - GradientBoosting: R²=0.611, RMSE=2.55 ✅
  - LSTM: R²=0.6258 ✅（已优化参数：seq_len=90, num_layers=3, epochs=80）
  - CNN1D: R²=0.449 ⚠️（epoch/seq_len 不足，需进一步调优）
- **网站入口**：`deep_research_web.py`，端口 7862
- **BUG**：Gradio 6.x State subscript bug → 已修复（改用全局变量）

### DeepClassify（子Agent-1：DeepClassify-Agent）
- **版本**：v1.1
- **功能**：信号/数据分类，支持 CNN1D / RandomForest / GradientBoosting / SVM 四种分类器
- **新增功能**：K-Fold CV、SHAP 可解释性、GB 后端选择（sklearn/LightGBM/XGBoost/auto）、模型对比
- **测试结果**（Iris 数据集）：RandomForest/GB Accuracy=93.33%，5-Fold CV=94.67% ✅
- **BUG修复**：RF/GB/SVM/CNN1D 相对导入错误 → 改为绝对导入（`from core.metrics`）
- **技术栈**：Python 3.12 + PyTorch 2.2.0 + scikit-learn + Gradio 6.9.0

### DeepDetect（子Agent-2：DeepDetect-Agent）
- **版本**：v1.2
- **功能**：时序异常检测，7种检测器（IsolationForest / Autoencoder / OneClassSVM / LOF / LSTM / Z-score / IQR）
- **新增功能（v1.1）**：LSTM 时序异常检测器、滑动窗口异常区间检测 `find_anomaly_intervals()`
- **v1.2 优化**：torch 升级 2.2.0→2.5.0（CPU）、Autoencoder Early Stopping（patience=5）、BatchNorm、ReduceLROnPlateau
- **测试结果**（Numenta NAB 温度异常数据）：7种检测器全部通过 ✅
- **技术栈**：Python 3.12 + PyTorch 2.5.0（CPU）+ scikit-learn + Gradio 6.9.0
