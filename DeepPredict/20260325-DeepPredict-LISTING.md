## 一、产品定位

### 核心定位
**DeepPredict** 是一款面向研究者的低门槛时序预测工具，专注于传感器信号的连续值预测分析。

### 支持的传感器信号类型
- **EMG（肌电）**：表面肌电、高密度 HD-EMG
- **ECG（心电）**：可穿戴 ECG、门诊 12 导联
- **PPG（光电容积）**：脉搏波、血氧饱和度
- **CGM（连续血糖）**：电化学葡萄糖传感器
- **加速度计**：运动信号、漂移校正
- **电化学传感器**：水质、气体、生物标志物

### 适用场景
| 场景 | 典型任务 |
|------|---------|
| 连续血糖预测 | 1型/2型糖尿病患者血糖趋势预测，提前预警低血糖事件 |
| 血压预测 | 基于 PPG/ECG 的无创连续血压估计 |
| HRV 分析 | 心率变异性长期依赖预测，压力/疲劳评估 |
| 传感器漂移校正 | 电化学传感器长期监测中的基线漂移校正 |
| 信号平滑 | 噪声传感器的预测值去噪，平滑输出 |
| 运动轨迹预测 | 加速度计/EMG 的运动模式连续预测 |
| 多步滚动预测 | 未来 1~N 步的滚动预测输出 |

## 三、模型功能矩阵

| 模型 | 类型 | 适用场景 | 状态 | 备注 |
|------|------|---------|------|------|
| LinearRegression | 线性基准 | 基线对比、快速探索 | ✅ 已实现 | 训练速度最快，适合理解数据基本关系 |
| RandomForest | 集成学习 | 通用预测、特征重要性分析 | ✅ 已实现 | 鲁棒性强，不易过拟合 |
| GradientBoosting | 集成学习 | 通用预测、高精度需求 | ✅ 已实现 | XGBoost/LightGBM 同级性能 |
| LogisticRegression | 分类 | 二分类预测（如血糖风险高/低） | ✅ 已实现 | 支持概率输出 |
| LSTM | 深度学习 | 长期依赖时序建模 | ✅ 已实现 | 处理长序列，捕捉时序相关性 |
| CNN1D | 深度学习 | 局部模式提取、短期趋势 | ✅ 已实现 | 计算效率高，适合快速原型 |
| PatchTST | Transformer | SOTA 时序预测 | ✅ 已实现 | 2023 年提出的现代时序 Transformer |

> **注意：** 所有模型均为独立跑通实现，不存在静默替换为备选模型的情况（P0 Bug `d3004cc` 已修复）。

## 六、典型用户场景

### 场景一：研究生论文（主力用户）
**情境：** 生物医学工程研究生需要将传感器时序数据预测结果用于学位论文。

**工作流：**
1. 导入实验室采集的 PPG/ECG/EMG CSV 数据
2. 选择 LSTM 或 PatchTST 模型一键训练
3. 系统自动输出 300 DPI Nature 配色时序对比图
4. SHAP 自动分析并打包特征重要性图
5. 一键下载完整 ZIP（含图表、数据、metrics、模型）
6. 图表直接插入论文，无需任何后期处理

**用户收益：** 无需学习 matplotlib/LaTeX，无需手动调图，节省至少 2~3 天图表制作时间。

---

### 场景二：临床研究者
**情境：** 糖尿病研究者需要用连续血糖（CGM）数据进行血糖趋势预测，并在论文中使用 Bland-Altman 图验证预测值与参考测量的一致性。

**当前支持：** 时序预测图 + 回归散点图 + SHAP 特征分析  
**规划中（P0）：** Bland-Altman 一致性图（医学验证必备）

**用户收益：** 从数据到可用于临床论文的图表，全流程在一处完成。

---

### 场景三：可穿戴设备算法团队
**情境：** 可穿戴设备团队需要快速迭代 PPG/ECG 信号预测算法，比较 RandomForest / LSTM / PatchTST 多模型性能。

**工作流：**
1. 导入历史传感器数据
2. 一键切换多模型训练
3. 并行比较各模型的时序预测图和误差 metrics
4. 选择最优模型导出

**用户收益：** 快速原型验证，无需在 Jupyter Notebook 中反复编写绘图代码。
